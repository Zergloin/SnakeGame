# Snake Game (Console / Pygame)

Классическая игра «Змейка», реализованная на Python с библиотекой Pygame. Присутствуют меню, настройки сложности и разрешения экрана, система рекордов и звуковые эффекты.

## Особенности

- Классический геймплей: змейка растёт при поедании фруктов, игра заканчивается при столкновении со стенами или собственным телом.
- Главное меню с пунктами: **Новая игра**, **Настройки**, **Выход**.
- Меню настроек:
  - **Сложность** (Лёгкий / Средний / Сложный) — влияет на скорость змейки.
  - **Разрешение** (800×600, 1024×768, 1280×720) — изменяет размер окна.
- Отображение текущего счёта и рекорда (High Score).
- Звук при поедании фрукта (`Sound/crunch.wav`).
- Управление на стрелки, навигация по меню стрелками ↑/↓ и Enter.

## Установка и запуск

1. **Клонируйте репозиторий:**

```bash
git clone https://github.com/Zergloin/SnakeGame.git
cd SnakeGame
```

2. **Установите зависимости:**

Убедитесь, что установлен Python 3.8+ и библиотека Pygame.

```bash
pip install pygame
```

3. **Запустите игру:**

```bash
python main.py
```

## Управление

### В игре

- `↑ ↓ ← →` — движение змейки

### В меню

- `↑ / ↓` — перемещение между пунктами
- `Enter` — подтверждение выбора

## Как это работает

При запуске открывается главное меню.

Выберите **«Новая игра»** — начнётся игровой процесс.

Змейка движется в последнем заданном направлении, при съедании красного квадрата (фрукта) увеличивается, а счёт растёт.

При столкновении с границей или собой игра сбрасывается, обновляется рекорд (если побит), и вы возвращаетесь в игру.

В настройках можно изменить скорость и разрешение окна.
